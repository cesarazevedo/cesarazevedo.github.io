Comunicados e avisos do condomínio

⚙️ Configurar integração com Google Sheets

1
Abra a planilha e vá em Extensões → Apps Script
2
Cole o código abaixo no editor e clique em Salvar:
function doGet() { var ss = SpreadsheetApp.openById('1kPpRfPsT3sL-6-5gCZzLwbb4zvxUVBOZHI7CtQ5GU2Q'); var sheet = ss.getSheetByName('Comunicados'); var values = sheet.getDataRange().getValues(); var headers = values[0]; var result = values.slice(1) .filter(function(row) { return row[0]; }) .map(function(row) { var obj = {}; headers.forEach(function(h, i) { if (row[i] instanceof Date) { obj[h] = Utilities.formatDate(row[i], 'America/Fortaleza', 'dd/MM/yyyy'); } else { obj[h] = row[i]; } }); return obj; }); return ContentService .createTextOutput(JSON.stringify(result)) .setMimeType(ContentService.MimeType.JSON); }
3
Clique em Implantar → Nova implantação, selecione tipo App da Web, em "Quem tem acesso" escolha Qualquer pessoa e clique em Implantar.
